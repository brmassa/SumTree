# Retired implementation and reference material

This directory preserves files retired during the typed-tree migration, from
commit `b9cfa6aafa942524b4fc3d9f847094e3330d946e`. Original paths are retained below this directory.
The summary files also preserve the removed runtime dimension classes.

These sources, tests, benchmarks, build files, and previous READMEs are historical
reference material. They are outside the active projects and are not built or run.
They can inform ports of cursors, edit batching, search helpers, keyed-item
utilities, and pooled-memory helpers to the typed API. They retain their original
behavior and defects; they are not supported compatibility implementations.

The active library is in `../SumTree`; its tests and benchmarks are in
`../SumTree.Tests` and `../SumTree.Benchmarks`. The license remains at `../LICENSE`.
